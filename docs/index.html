editcontext-editor

A rich text editor library built on the EditContext API — no contenteditable, DOM-based, with its own JSON document model and full IME support.

GitHub · W3C spec · MDN

Your browser doesn't support the EditContext API yet. The demo below needs Chrome or Edge 121+ (Safari and Firefox are still working on it), so the editors won't accept input here — but you can still inspect the page and the code.

Full editor

Try typing (including with an IME — e.g. Japanese or Chinese input), Ctrl/⌘+B for bold, Enter for new paragraphs, Shift+Enter for a line break, Tab inside tables to move between cells, paste from other apps, and undo/redo.

How it works

    
    
      
  • 
        The editable element is a plain <div> — not contenteditable — with an
        EditContext attached. All text input (keyboard, IME, emoji picker, dictation…) flows through
        the EditContext's plain-text buffer and is reported back as textupdate events.
      
    • 
      
  • 
        The library mirrors that buffer into its own JSON document model (paragraphs, headings, tables,
        inline/block images, text marks) and re-renders the DOM from the model on every change.
      
    • 
      
  • 
        A position map translates between model locations, buffer offsets and DOM points, so selections,
        IME character bounds (characterboundsupdate) and composition underlines
        (textformatupdate) all line up — candidate windows appear exactly where you type.
      
    • 
      
  • 
        Formatting requests (bold/italic/…), Enter, paste, cut and undo arrive as cancelable
        beforeinput events on the element and are handled by model operations.
